# 首页设计说明（Landing Page）

状态：评审中
最后更新：2026-11-05

## 一、设计目标

首页是产品气质的第一落点，用户在进入鱼缸之前先被"安静下来"。要求大气、克制、留白，不做营销页式的信息堆砌。

## 二、创意来源

《庄子·秋水》濠梁之辩：

> 庄子与惠子游于濠梁之上。庄子曰："鯈鱼出游从容，是鱼之乐也。"
> 惠子曰："子非鱼，安知鱼之乐？"

"知鱼"之名即出于此：知鱼之乐，亦知用户之压力。首页用意境而非说教表达这层含义。

## 三、视觉方案

### 背景（全屏 Three.js）

- 全屏深蓝黑调（与鱼缸页 `#0e1722` 体系一致），纵深雾效；
- 一群低模鱼剪影（约 20-30 条，InstancedMesh）在景深中从容游动，方向舒缓、速度慢，对应"出游从容"；
- 顶部投下数道体积光束（简化半透明几何体），水中漂浮微粒与少量气泡；
- 鱼群为深色剪影、边缘带微弱冷色高光，不抢文字。

### 文字排版（居中，大量留白）

| 元素 | 内容 | 处理 |
|---|---|---|
| 品牌字 | 知鱼 | 超大字号、细字重，视觉主体 |
| 拼音 | ZHIYU | 小字、宽字距，置于品牌字上方 |
| 典故文案 | 子非鱼，安知鱼之乐？ | 中号字、低透明度，品牌字下方 |
| 行动按钮 | 观鱼 | 透明底描边按钮，hover 时填充；不使用"入口/开始"等系统词 |
| 按钮副文 | 进入我的鱼缸 | 极小字、低透明度 |

按钮文案定为"观鱼"：直接呼应濠梁观鱼的动作，两个字干净，动作感与文化感兼具。

## 四、交互

- 点击"观鱼" → 路由跳转 `/tank`，进入鱼缸；
- 背景场景持续慢节奏运行，鼠标移动时相机做极轻微视差（可选，幅度控制在不引起眩晕的范围）；
- 页面切换不做花哨转场，淡入淡出即可；
- 无障碍：按钮可 Tab 聚焦、可回车触发，文字与背景对比度满足可读性。

## 五、路由结构

| 路径 | 页面 |
|---|---|
| `/` | 首页 LandingPage（全屏背景场景 + 品牌文案） |
| `/tank` | 鱼缸页 TankPage（现有 M0 骨架内容） |

## 六、性能要求

- 首页背景单 draw call（InstancedMesh）+ 一套粒子，低端设备自动降粒子数；
- 首屏可交互时间不劣化于当前骨架水平；
- 跳转鱼缸页后释放首页背景场景资源，避免常驻显存。

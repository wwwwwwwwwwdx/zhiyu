# M1 迭代记录（一）：经济、装备与鱼群

状态：已确认
最后更新：2026-11-05

## 本轮实现

### 引擎（纯 TS 内核）

- 金币经济：开局 500 金币，全部购买行为扣减金币；
- 装备目录（7 件，3 类）：
  - 过滤器 3 档（壁挂/滤桶/底滤），capacity 与 flow 真实决定细菌容量与溶氧；
  - 灯具 2 档（普通 LED/水草灯）；加热棒 2 档（50W/100W）；
  - 支持购买入库存、已拥有装备切换安装；
- 鱼类目录（8 种）：价格、适宜温度区间、成年体重、群游最小数；
- 混养规则：神仙鱼与虎皮鱼互斥，冲突时拦截购买并说明原因；
- 缸内密度上限（总重量 60g）校验；
- 事件去重：警告仅在指标越限的上升沿触发，解除后可再次告警；硝化建立只通知一次；
- 命令统一返回 `CommandResult { ok, reason }`，失败原因可展示给用户。

### 渲染

- 鱼群随引擎快照动态增减（Map 管理 mesh 生命周期），不再硬编码 3 条；
- 行为状态驱动游动速度（焦躁加速、躲藏/生病减速）。

### 界面

- 右侧栏：金币余额、鱼店、装备店（购买/安装/使用中状态）、日常操作、水质、事件；
- 命令失败时顶部提示具体原因。

## 验证结果

- 单测：8 个用例全过（空缸喂食拦截、买鱼扣费、混养冲突、装备安装、密度、换水、确定性等）；
- 构建：TypeScript strict 类型检查 + Vite 生产构建通过；
- 路由：`/` 首页、`/tank` 鱼缸页均可访问。

## 第二批：存档、离线与生命周期闭环

### 持久化（`src/persistence/`）

- 基于 idb 的 IndexedDB 仓储：`saveGame / loadGame / clearSave`；
- 引擎新增 `PersistedState` 与 `getPersistedState`，`createEngine(initial)` 支持从存档恢复全部状态；
- 自动保存：每 15 秒定时 + `visibilitychange` 页面隐藏时落盘，`beforeunload` 兜底（异步保存不保证完成，主靠前两者）。

### 离线推演

- 存档记录真实时间戳，回归时按 `TIME_SCALE` 换算离线游戏时长，封顶 8 游戏小时；
- `fastForward` 批量推演并对事件去重，右上角展示"你离开期间"摘要卡片。

### 生命周期闭环

- 群游不足：买鱼后同种类数量低于 `minSchool` 时给出提示（不阻断）；
- 死亡移除：health 降至 0 的鱼从引擎移除并通知，渲染层同步回收 mesh 与材质。

## 第三批：开缸养水、新手引导与迁移机制

### 开缸养水（真实氮循环前置）

- 新增 `startCycling` 命令：养水期每 tick 注入少量氨源（模拟残饵），驱动硝化细菌建立；
- 未建立硝化系统时 `buyFish` 被拦截，引导玩家先养水；
- 判定标准：两类细菌（B1/B2）均 > 5 且 NH3 回落至 0.2 以下，触发一次"硝化系统建立"事件并停止养水。

### 关键模型缺陷修复：细菌休眠

- 问题：硝化建立后氨源中断，原模型在无底物时仍以固定 `bacteriaDecay=0.002` 持续衰减，分段诊断显示 B1/B2 从 t=100 的 6.8 一路衰减到 t=7200 的 0，硝化系统崩溃；
- 修复：
  - 无底物时细菌进入休眠，decay 归零（只有存在底物时才做衰减平衡）；
  - `bacteriaDecay` 从 0.002 下调至 0.0001；
- 新增测试：空缸再等 1 游戏天后 B1/B2 仍 > 5，验证休眠保留。

### 新手引导（`GuideOverlay`）

- 5 步遮罩：欢迎 → 开始养水（等待硝化建立）→ 去鱼店放第一条鱼 → 喂食 → 完成；
- 目标区块高亮（鱼店 `guide-fish-shop`、喂食按钮 `guide-feed-btn`），步骤随引擎状态自动推进；
- 完成后 `guideDone` 持久化，老玩家不再弹出；
- 快照接口 `Snapshot` 补充 `nitrogenEstablished / cycling / guideDone` 三个只读字段供 UI 使用。

### 存档迁移机制（`src/persistence/migrate.ts`）

- 迁移函数注册表：按"源版本"逐版本升级，缺失迁移路径时快速失败，避免静默使用脏数据；
- 当前版本 v1，无实际迁移路径，结构先就位；加载存档时统一经过 `migratePersistedState`。

### 长时运行稳定性

- 新增 7 游戏天（含放鱼）长时推演测试：NH3 有界、NO3 不超 100、数值有限无 NaN；
- 渲染层 `Renderer` 与 `LandingScene` 均具备 `dispose` 与 geometry/material 回收路径（代码审计确认，浏览器侧自动泄漏检测仍待后续）。

# M2 出口性能验收

状态：评审中（动态性能指标待前台实测）
最后更新：2026-11-05
验收标准（来自路线图）：关键性能指标达到 **30 FPS+**，兼容 **Chromium 最新两个版本**，达到灰度发布品质。

## 一、结论先行

- 代码与构建层面已具备灰度条件：自动化测试全绿、构建拆包合理、无控制台错误、资源释放与降级路径齐备。
- 但 **30 FPS+ 与多版本兼容这两项出口标准，尚未在可见浏览器完成实测**。当前自动化浏览器页面处于隐藏状态（`document.visibilityState=hidden`），浏览器对隐藏页暂停 `requestAnimationFrame`，无法测得动态 FPS。
- 因此本报告不直接宣称性能达标，而是列出已验证事实、环境限制与一份可直接照做的前台验收步骤，由前台实测结果支撑最终 Go/No-Go。

## 二、已客观验证项

### 1. 生产构建与拆包

| chunk | 未压缩 | gzip | 说明 |
|---|---|---|---|
| 业务代码 | 112.5 kB | 37.7 kB | 引擎 + UI + 埋点 |
| react | 161.7 kB | 52.8 kB | 强缓存，跨版本稳定 |
| three | 521.3 kB | 131.9 kB | 独立缓存，首屏后复用 |

- `manualChunks` 已将三者拆分，利于并行加载与长效缓存；three 体积属固有开销，已调高警告阈值消除误报。

### 2. 自动化测试

- 共 4 个测试文件、21 个用例全部通过，含：
  - 氮循环与引擎长时稳定性（15）；
  - 性能监控 FPS 采样、暂停恢复保护、降档逻辑（3）；
  - 埋点事件分发与本地存储（2）；
  - 存档迁移（1）。

### 3. 浏览器内静态验证（隐藏页）

- 页面加载无控制台错误；
- 喂食后 localStorage 正确写入 `feed` 埋点事件；
- 水质面板 6 个状态灯圆点正确渲染，NO3 升高触发黄灯；
- 资源 dispose 机制完整（M1 已验证多轮路由切换后 canvas 始终为 1，无 GPU 泄漏）。

### 4. 降级代码路径

- 渲染循环按秒采样 FPS，低于 30 自动降档并带滞后；
- `setQuality` 经 `setPixelRatio → resize` 生效，相关纯逻辑由单测覆盖。

## 三、受环境限制未能验证项（如实记录）

| 项目 | 限制原因 |
|---|---|
| 动态 FPS 实测 | 隐藏页 rAF 被暂停，画面为静态帧，FPS 读数不更新 |
| 自动降档真实触发 | 无法产生真实持续低帧，仅验证了代码与单测 |
| DPR>1 下像素比差异 | 实测该环境 DPR=1，高/低档 canvas 尺寸均为 981×1251，无差异 |
| 进入全屏 | Fullscreen API 要求真实用户激活且页面可见，隐藏自动化点击被拒绝 |
| Chromium 两版本兼容 | 仅具备单一自动化 Chromium，无第二版本环境 |

## 四、发现的覆盖缺口（需在后续收敛）

- 画质预设 `QUALITY_PRESET` 定义了 `maxPixelRatio / particles / postProcessing` 三个字段，但当前**只有像素比有实际消费者**：
  - 鱼缸 Renderer 没有粒子系统与后期处理，这两个字段暂无可控对象；
  - 首页 LandingScene 的 220 个粒子与 24 条 InstancedMesh 为硬编码，未接入档位。
- 现状不影响 M2 功能（像素比是最主要、最有效的降级杠杆），但在引入正式粒子/后期效果时，必须让对应渲染器消费这些字段，否则"三档控制"名不副实。

## 五、前台验收步骤（请在可见浏览器执行）

1. 启动 `npm run dev`，前台打开 `http://localhost:5173/tank`；
2. 观察右侧调试区 FPS 读数：稳定后应持续 ≥ 30，目标接近 60；
3. 保持页面观察 1–2 分钟，确认无异常自动降档；可手动切高/中/低，观察画面清晰度与流畅度变化；
4. 点击"全屏观赏"，确认进入全屏、隐藏操作栏、Esc 与悬浮按钮均可退出；
5. 重复喂食、换水、灯开关、放鱼等动作，无卡顿、无报错；
6. 在最新稳定版与上一主版本 Chromium 内核浏览器（如 Chrome 当前版与前一版，或 Edge 对应版本）分别重复 2–5，确认行为一致。

## 六、剩余不确定性

- 真实设备（尤其低端 Windows、核显笔记本）上的动态 FPS 与 GPU 内存表现，本阶段无数据，需在灰度设备上补充；
- 正式 glTF 美术资产接入后，draw call、贴图内存与骨骼动画开销会改变性能画像，需在资产接入后重新评估本报告。
